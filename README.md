# Mẹ con ăn ý trên Zalo OA

Bản mô phỏng học thuật cho hoạt động “Mẹ con ăn ý” của MILO trên Zalo OA.

Website minh họa luồng trải nghiệm gồm câu hỏi khám phá, lời mời, đoán đáp án, kết quả, chọn lịch vận động và lưu thẻ hẹn. Đây là bản demo giao diện; website không kết nối Zalo OA thật, không có backend và không gửi dữ liệu cho MILO hoặc Zalo.

Truy cập web: <https://hazymoon873373-droid.github.io/milo-me-con-an-y/>
